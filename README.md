# Superstore Sales Analysis

## 📊 Project Overview

Analysis of Superstore sales data to understand revenue trends, regional performance, product performance, customer segments, and seasonality.

## 🎯 Objectives

* Analyze sales performance across regions and categories
* Identify top and low-performing products
* Study monthly and seasonal sales trends
* Calculate important sales KPIs
* Provide actionable recommendations

## 🛠️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📌 Key KPIs

* Total Revenue
* Total Orders
* Total Customers
* Total Products
* Average Order Value
* Average Shipping Days

## 📈 Analysis

The project includes:

* Sales trends
* Regional analysis
* Category & sub-category analysis
* Top and bottom products
* Customer segment analysis
* Shipping mode analysis
* Seasonality analysis

1. Focus on high-performing regions.
2. Maintain inventory for high-revenue products.
